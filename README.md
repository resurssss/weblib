# 3. Реализованный функционал

## Общая структура проекта

Проект разделён на две независимые части:

* frontend — клиентское приложение на Vue 3;
* backend — серверная часть на FastAPI.

Также используется база данных SQLite и docker-compose для совместного запуска сервисов.

---

## Компоненты приложения

В ходе выполнения работы были реализованы следующие компоненты.

### AppHeader.vue

Используется как верхняя панель приложения.

Содержит навигацию между разделами электронной библиотеки.

## Использование возможностей Vue 3

### Реактивность

Используются:

* ref;
* reactive.

---

### Computed

Computed используется для фильтрации и сортировки списка книг.

В зависимости от выбранных параметров пользователь получает нужный список книг без дополнительных запросов к серверу.

### Watch

Watch используется в форме редактирования книги.

При изменении объекта initialBook автоматически обновляются значения всех полей формы.

```

```

Он применяется:

* при загрузке списка книг;
* для получения количества книг;
* для установки фокуса в поле ввода.

Используются для передачи данных между компонентами.

Например:

* BookItem получает объект книги;
* BookForm получает объект книги для редактирования.

Реализованы события:

* edit;
* delete;
* toggle-status;
* toggle-favorite;
* toggle-reserve.

Также реализована проверка корректности введённых данных.

# 5. Примеры кода

## Пример использования компонента BookItem

```vue
<BookItem
  v-for="book in filteredAndSortedBooks"
  :key="book.id"
  :book="book"
  @edit="editBook"
  @delete="deleteBook"
  @toggle-status="toggleStatus"
  @toggle-favorite="toggleFavorite"
  @toggle-reserve="toggleReserve"
/>
```

Компонент получает объект книги через `props`, после чего отображает информацию о книге и отправляет события родительскому компоненту с помощью `emit`.

---

## Пример вычисляемого свойства (computed)

```javascript
const filteredAndSortedBooks = computed(() => {
  let result = [...books.value]

  if (statusFilter.value === 'available') {
    result = result.filter(book => book.is_available)
  }

  if (sortType.value === 'title') {
    result.sort((a, b) => a.title.localeCompare(b.title))
  }

  if (sortType.value === 'date') {
    result.sort((a, b) => new Date(b.created_at) - new Date(a.created_at))
  }

  return result
})
```

Вычисляемое свойство автоматически фильтрует и сортирует список книг без дополнительных запросов к серверу.

---

## Пример серверного метода

```python
@app.get("/api/books")
def get_books(db: Session = Depends(get_db)):
    return db.query(Book).all()
```

Метод получает список книг из базы данных SQLite и возвращает его клиентскому приложению.

Собрать контейнеры:

```bash
docker compose build
```


```
http://localhost:8080
```

```bash
docker compose down
```

# 8. Выводы

В ходе выполнения практической работы было разработано полноценное SPA-приложение «Электронная библиотека ElectoLibrary» с использованием современных технологий веб-разработки.

В процессе работы были изучены основные возможности Vue 3, включая реактивность данных, компоненты, маршрутизацию, формы, вычисляемые свойства и наблюдатели. Также был освоен процесс контейнеризации приложения с помощью Docker и Docker Compose. Клиентская часть собирается через Vite и раздаётся сервером Nginx, а серверная часть запускается с использованием FastAPI и Uvicorn.

В результате выполнения работы были закреплены навыки построения SPA-приложений, организации клиент-серверного взаимодействия, работы с REST API, базами данных и контейнеризацией приложений.
